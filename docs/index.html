StoryStash – Story & Post Saver

A free Chrome extension for keeping Instagram™ posts and stories for personal offline viewing. One click on instagram.com saves exactly the item you are looking at, in the largest size Instagram provides, with a clear file name like username_2026-11-09_14-05-07_C1a2B3c4D5e_2.jpg.

Features

  • A button on every post photo, video, reel and story.
  • Posts with several photos: each photo has its own button, so you get the one on screen.
  • The largest size Instagram provides, not the small preview; photos are saved as JPG, videos as MP4.
  • File names with username and date; optional folder per user.
  • No account, no ads, no tracking. Nothing is sent to the developer.

Install

Install from the Chrome Web Store (link will appear here once published), then open instagram.com.
